The opportunity

Air-gapped Redaction Workbench: target users are law firms, compliance teams, journalists, and regulated SMBs that handle sensitive PDFs locally. Painful problem: they need to redact text and metadata correctly without sending documents to a cloud service, and manual workflows are slow and error-prone. Value proposition: a native macOS app that finds redactable text, applies permanent redactions, strips metadata, and exports a clean evidence pack entirely offline.

Objective for this build

Build the smallest Swift-only macOS prototype that opens a local PDF, lets the user mark text for redaction, permanently applies the redactions, strips document metadata, and exports a sanitized PDF plus a simple audit log.
