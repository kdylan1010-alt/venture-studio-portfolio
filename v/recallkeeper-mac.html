The opportunity

RecallKeeper, a native macOS application for ordinary households managing appliances, electronics, toys, tools, and other owned products. The painful problem is that proof of purchase, model identifiers, warranty terms, and recall notices live in incompatible receipts, labels, photos, PDFs, and government databases. Its value proposition is private, local extraction of product identity and ownership evidence, followed by authoritative recall matching, warranty-date calculation, clear confidence indicators, actionable guidance, and exportable records without accounts, subscriptions, paid APIs, or uploading personal documents.

Objective for this build

Build the useful RecallKeeper macOS application and package it as a .dmg using swiftc and Apple system frameworks alone. The graphical app will accept dragged images and PDFs; run Vision OCR and PDFKit text extraction; detect brands, model numbers, serial numbers, UPCs, purchase dates, prices, and warranty language from messy input; provide a correction/review interface with confidence warnings; persist products, source files, settings, and dismissed matches between launches; fetch and combine public CPSC and SaferProducts recall records through URLSession on demand; rank likely recall matches with explainable evidence; calculate likely warranty windows; show progress, offline states, parsing failures, and recovery actions; and export selected ownership records and recall findings as CSV and printable PDF. Verification will exercise mixed scans, rotated photos, multipage PDFs, malformed API responses, duplicate imports, relaunch persistence, correction flows, exports, and DMG launchability.

The recommended pricing hypothesis is ESTIMATE $29 one-time, compared with the cheapest credible alternative: a free spreadsheet plus manual government-database searches.

The Four Actions analysis positions RecallKeeper around eliminating accounts, cloud uploads, subscriptions, and exhaustive home-inventory work while raising privacy, evidence preservation, and recall-match transparency. This is not yet a demonstrated blue ocean because free manual searches remain adequate for infrequent use and adjacent inventory products could add similar matching.
