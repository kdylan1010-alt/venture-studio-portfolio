The opportunity

A privacy-first native macOS utility for consultants, agencies, and small businesses that scans local files, PDFs, and images for secrets, PII, and accidental sharing risks, then produces a local risk list and redaction/export report. Pain: sensitive data leaks from Desktop, Downloads, and shared folders before anyone notices. Value proposition: instant offline visibility without uploading files to a cloud service.

Objective for this build

Build a one-window SwiftUI macOS prototype that lets the user choose a folder, scans a seeded sample corpus locally using only Apple frameworks and swiftc-compatible code paths, flags emails, SSNs, card numbers, and common API-key patterns, and displays/export a results list. Verify it against a small test set with known hits and misses.
